# 0.5.55/0.5.56 发布源核查(2026-09-13)

## 事实(逐项实测)

- registry 有 0.5.55/0.5.56;本地与远端 master 的 `package.json` 停在 **0.5.54**,且全仓无 0.5.55/0.5.56 的 release 提交(分支亦无)

## 结论

0.5.55/0.5.56 的发布源就是当前 master 线(自工作区发布),**不是未合并分支**;漂移仅是形式性的:发布时未把版本号 bump 提交回仓。生产部署 0.5.56 与开发线内容一致,此前"部署超前开发仓"的表述按内容口径不成立,按版本号口径成立。
