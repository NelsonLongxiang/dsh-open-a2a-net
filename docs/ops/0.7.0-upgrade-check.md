## 1. 宿主能力下界与证据

**最低支持宿主包族：@deepseek-ai/dsh-agent >=0.1.7-alpha.2，实际运行 Agent 必须提供 followup(UserMessage)；默认循环实现相应为 @deepseek-ai/dsh-agent-loop 0.1.7-alpha.2 或更新的兼容实现。** 这里是包版本，不是声称某个统一 DSH app/GUI 版本号。私有适配器即使版本号满足，也必须实现能力；缺方法显式拒绝任务，不降级 steer。

本版保留原 peer 范围，不虚构更高最低号：

- npmjs 的真实 @deepseek-ai/dsh-agent@0.1.7-alpha.2 包，SHA-1 056a531547e97b70bbedb36bd5b3f168634e700e；其 lib/types/runtime-types.d.ts:188–192 声明 followup(message:UserMessage)，说明独立普通下一轮并唤醒。
- 同版 @deepseek-ai/dsh-agent-loop@0.1.7-alpha.2 包，SHA-1 cdba6aa2ea322e1b1819a95dff837c31314a33fd；lib/index.js:806–807 实际实现 followup → send(input,"next-turn",true)。不是从 README 的文字推导实现存在。
- 抽查 alpha.1、rc.1、rc.2 的 Agent 声明也有方法，因此没有证据要求把当前 >=alpha.2 收紧到 rc.2。alpha.1 的存在不表示本插件把其他 peer 的整体下界下调。
- 宿主源码历史 b02b438667d29b4cdc3ec83e4ea95404945e9d7e 的 intent-named-agent-delivery 实施记录解释 followup 的语义；当时 package private 0.0.1，不把该内部版本当 npm 最低号。
- 本机只读 coherent host lib 专项曾在宿主 fcc0ad462172522aaf5c93a7b2e01f6b9f0b0159、Agent/Loop/Session 0.2.2-rc.1、Node v24.12.0 运行维护锁/FIFO/独立轮/idle/cold消费。该专项是作者环境证据，不冒称 alpha.2 全宿主场景或所有节点均已运行；默认 CI 不依赖该外部检出。

## 3. 洁净双导出 / 独立安装 / 无陈旧 lib

共享检出不能 clean（保护既有交接文件），禁止 worktree / 独立 clone。评审席已批准精确 git archive 方案：同一候选提交导出到两个全新空目录 A/B，无 .git、无历史 lib、无共享 node_modules；各自独立 frozen install 和构建。原 .gitattributes 无 export-ignore / export-subst，archive 不漏文件、不替换正文。证据比较 archive 全部普通文件的路径、git blob 哈希与 git ls-tree -r；不以“看起来干净”代替字节核对。

```sh
git rev-parse "<CANDIDATE_COMMIT>" "<CANDIDATE_COMMIT>^{tree}"
git archive --format=tar --output="<SOURCE_TAR>" "<CANDIDATE_COMMIT>"
tar -xf "<SOURCE_TAR>" -C "<EMPTY_BUILD_A>"
tar -xf "<SOURCE_TAR>" -C "<EMPTY_BUILD_B>"
# A、B各执行一次，必须独立node_modules，不复制或链接共享检出：
pnpm --dir "<BUILD_ROOT>" install --frozen-lockfile --ignore-scripts
pnpm --dir "<BUILD_ROOT>" run build
# BUILD_ROOT 起初必须没有lib；如果曾构建，该目录不再是本轮洁净输入，另选全新目录。
npm pack "<BUILD_ROOT>" --ignore-scripts --pack-destination "<OUTPUT_DIR>" --json
tar -tzf "<CANDIDATE_TGZ>"
node -e 'const fs=require("node:fs"),c=require("node:crypto");for(const p of process.argv.slice(1))console.log(c.createHash("sha256").update(fs.readFileSync(p)).digest("hex"))' "<A_TGZ>" "<B_TGZ>"
```

安装阶段禁执行prepare，保证构建开始前lib为空；随后显式 build。tsconfig 的宿主类型 fallback 只读，既不在该宿主检出构建，也不把其 node_modules 作为本包安装结果。精确记录两次 Node/pnpm/npm/平台版本及 frozen lock 哈希，不把下载缓存共享误说成 node_modules 目录共享。正常 pnpm 自有内容寻址存储不等于复制项目node_modules。

包内 lib 每个 JS / d.ts / source map 必须对应 src 的源文件；允许的明确生成物只有 lib/client.js(+map)（由 src/client/index.ts 等合成）和 lib/skill/**（源为 src/skill/**）。检查不能仅依赖新包文件名数；须列出无法回指源码的多余文件并拒绝。比较0.6.43的新增/删除路径与两份 tar -tzf 清单一并留证。
