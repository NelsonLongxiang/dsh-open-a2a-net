# 设计卡：A2A 面板瘦身——仅留最近网络动态，管理面迁入规划视图

日期：2026-08-31。主人指令：「A2A 网络面板仅保留最近 A2A 网络消息动态，其他功能根据情况迁移到规划视图」+ UI/UX 取向。

## 现状盘点（A2aControl.tsx，761 行七块）

| 现有块 | 裁决 | 目标 |
|---|---|---|
| 会话节点列表（join/leave toggle、点击开会话、搜索、分组选择器） | **迁移** | 规划视图卡片 + 右键菜单（join/leave/promote/散队已有）；**网络层入网/退网无入口是本窗唯一功能缺口**（画布队加入≠入网），本窗补 node 菜单「入网/退网」 |
| 画布队管理（建队/加成员/解散） | **迁移**（已就位） | 规划视图菜单已全量覆盖 |
| 远端队列表 | **迁移**（已就位） | 规划视图联邦层远端节点卡 |
| 对等节点网格（URL+质量分） | **迁移** | 联邦层 peer 卡；质量分随 peer 卡子行（本轮可缺省，非指令要点） |
| 会话分组标签 | **迁移**（已就位） | 规划视图框/拖拽 |
| 最近路由动态（活动环） | **保留** | 面板唯一内容 |
| 在途路由 + 欠回执 | **保留** | 属“动态”语义（正在路上/债务面），融入动态 feed 顶部 |

## 面板瘦身后形态

触发钮（未读徽章）→ 弹层三段：标题+版本 → **规划视图入口行**（观测 3D / 规划 2D——从面板通往管理面的显式导航，因本窗把管理搬走，此行由从属信息升级为主导航）→ 动态 feed（在途路由脉冲行 + 欠回执块 + 活动环）。

### UX 准则（ui-ux-pro-max 取向）

- 方向glyph（←入/→出）带 aria 语义；成败不只靠颜色——失败行加 ✕ 文本标记
- feed 容器 `aria-live="polite"`，动态更新不夺焦
- fresh 行高亮遵守 reduced-motion（@media prefers-reduced-motion 关闪烁）
- 空态给引导（无动态时指向规划视图入口）
- 活动行点击跳转会话保留（GUI 内）

## 缺口与后置

- **打开会话（从规划视图 2D 页）**：规划视图独立 URL（/__dsh_a2a_nexus/），跨页打开会话需 GUI 会话 deep-link——本轮不发明，登记后置；GUI 内经动态行跳转保持可用。
- 远端 quality 分进 peer 卡子行：小改进，非指令要点，后置。
- 会话搜索：规划视图无搜索——会话规模已平铺在图上（登记观察，用户有需再加）。

## 非目标

不动宿主端 state 面字段（客户端仅裁剪渲染）；不动规划视图既有菜单行为。
