# Original marketplace illustration sources

These three SVG/PNG pairs are original illustrations created for Open A2A Net. They explain the Superagent workflow in the stable release using a simulated product-research request. They are not screenshots of DeepSeek Harness, the plugin UI, internal sessions or production tasks.

- 01-superagent-flow: request, router, fixed member and owner feedback.
- 02-ticket-progress: progress, waiting on an owner decision, and a reviewable result.
- 03-owner-decisions: a question, alternatives, recommendation and decision returning to a ticket.

The SVG files are editable sources. PNGs are browser-canvas rasterizations of those sources, not screen captures. The marketplace manifest uses PNG files in this repository. Every illustration carries an explicit simulated/non-UI notice in Chinese and English.

Source and raster artwork use this repository’s MIT license. No third-party icons, font files, screenshots or other image bytes are bundled; system font names merely select fonts already present on the rendering system.

Capability reference: the guide shipped with stable 0.8.3 at commit 1c96510912c4a87786d3fc2ee513cac0bb87904f. The artwork intentionally uses a version-independent SUPERAGENT TEAMS label. Artwork is explanatory, not a compatibility or acceptance test.

Community consumers discover the 1–8 curated PNG paths through the root screenshots.json next to package.json. The schema field is named screenshots, but these entries are explicitly disclosed illustrations, not actual product UI. Reviewers may request further labeling.
