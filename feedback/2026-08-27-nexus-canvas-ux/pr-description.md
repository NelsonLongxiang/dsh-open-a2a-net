# PR 描述（贴入 Gitee PR 正文）

## 概要

按 `feedback/2026-08-27-nexus-canvas-ux/design.md` 的四步路线图，为 A2A 联邦网络补齐**规划面**：2D 无限画布（规划模式）与既有 3D 观测模式双模共存，tab 切换、共享同一 state 数据源，零 host API 新增（只消费锁定 v1 契约的既有写面）。

## 分阶段内容

- **A · 观测面修复**：已随此前的 PR 先行合入 master（不在本 diff 内）。本分支仅携带其两个后续修复：节点退役的 GPU 释放与映射清理、观测/规划双模焦点与 z 序隔离。
- **B · 规划模式骨架**：点阵世界层、172px 节点卡（live/cold/P 徽标）、队框（色相哈希+居中标题栏）、星形成员边（跨队虚线）、布局持久化回路（写路径 + 800ms 防抖 + 存盘灯 + pagehide flush）、框选/拖拽/键盘全等。
- **C · 组队交互**：建队（框选≥2→命名对话框→串行 create+add）、入队/离队（拖放命中 + 侧沟命中测试）、调优先级（帧内 y 排序 → 最小 remove+add 序列；置顶路由）、散队；乐观更新 + 按队作用域 undo + host 错误原文 Toast；右键菜单全键盘等价（Shift+F10/Space/Delete/Alt+↑↓）。
- **D · 活动/联邦层**：peer 徽章列、inFlight 活动边（整秒年龄标签、reduced-motion 静态等价）、联邦线（gns referral 首辐标注）、状态条 inFlight 计数 + 点击飞行定位；mockhost `?demo=1` 演示数据集。

## 关键设计裁决（详见 implementation-notes.md）

1. 空白拖拽=框选（Figma 惯例，用户裁决）；平移=Space/中键，缩放=Ctrl+滚轮指针锚定。
2. 布局文档 `{x,y}` 量纲 = 2D 卡中心 px（契约第 6 条留痕）；3D 观测镜头**重投影**消费（质心归零+包络缩放，每 poll 跟随），不按绝对量纲消费。
3. 建队 ids 按 y 升序（优先级隐喻一致、确定性），替代字面"框选顺序"。
4. 未保存节点座位：2D 卡尺度三环 / 3D 极环（保存后收敛同一文档）。
5. 队框标题栏居中 + 固定高 24px：星形锚点可纯计算。

## 实施期发现并修复

- border-box 缺失 → 卡片实渲染 216×74 vs 常量 172×56（成员边偏移/队框出框）；
- 队框元素赢下真实指针命中测试 → 框内成员卡无法拖拽（合成事件测试直指元素故未捕获）→ 稳定分层 + 框体事件透明；
- 联邦线锚点横穿卡场 → 侧沟短桩（Liang-Barsky 0 穿越）；
- 滚轮平移反轴 → 跟随原生增量；
- 并行会话回归：`meshesById.set` 丢失（Tab 花名册/退役/成员边全灭）。

## 验证

- 根套件 + 子包套件新增 80+ 用例（纯几何/动作代数/wire 队列/jsdom 交互/联邦层）；
